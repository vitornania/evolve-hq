# Make an ad variation

Apply Evolve’s iteration process to a specific parent ad.

## Inputs

Parent ad, results, and the element to change.

## Steps

1. Identify the parent ad, actual results, control version, and test goal.
2. Change one material variable and preserve the other cues that define the control.
3. Return a comparison-ready variation, prediction, asset list, and measurement plan.

## Deliverable

An iteration brief with a testable change.

Keep source details with the deliverable. Label assumptions and missing evidence. Preserve the scope and any approvals supplied by the user.
