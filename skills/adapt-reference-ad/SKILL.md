# Adapt a reference ad

Use the structure of a supplied static ad for your own product.

## Inputs

Reference image, product, verified claims, and target format.

## Steps

1. Describe the reference's hierarchy, composition, idea, and proof device.
2. Create an original execution for the new product. Replace source branding, claims, photos, and copy with supplied or approved material.
3. Deliver a layout brief and note any evidence or asset gaps.

## Deliverable

An adaptation brief and revised content.

Keep source details with the deliverable. Label assumptions and missing evidence. Preserve the scope and any approvals supplied by the user.
