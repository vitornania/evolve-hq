# Adapt a reference ad

Read [reference review](references/reference-review.md) first. Use it to define the test from product and customer evidence, review the full authorized inventory when asked to pick a template, and map every image and text slot to the same role. A supplied reference goes straight to inspection. Keep the original source read-only.

For every substantive ad or template selection, start with the [product research handoff](references/reference-review.md#start-with-product-research). Reuse saved findings when available, gather missing evidence before final copy, and trace each on-image claim and supporting visual back to a finding.

Preserve the source's message sequence, syntax, line count, type metrics, and visual hierarchy. Replace each benefit, mechanism, proof, offer and visual with its closest supported counterpart for the target product. Preserve typefaces verified from native design or PDF metadata. Disclose font substitutions. Check all visible copy, props, icons and product imagery, including embedded labels and secondary panels.

For a brief, return the review counts, selection rationale, and source-to-target map. For a build, use [local rendering](references/local-rendering.md) or the connected editor the user requests. Keep copy, product and background independently editable. Verify dimensions and compare the result with the reference and at phone size. Deliver a PNG, layered source and any unresolved fidelity or evidence issues.

## Verify what the picture promises

1. Read the strongest impression created by each panel with the copy hidden. A chart suggests a measurement, a portrait beside quotation marks suggests testimony, and a before/after pair suggests a result. Assign those implications their own evidence and permission checks. A flavor can fill a sensory slot. A benefit slot needs a corresponding buyer outcome. Count independent promises within a slot. A two-benefit headline requires two distinct supported outcomes. Two phrasings of one benefit, a flavor, or a feature do not supply the second.
2. If the source depends on proof the product lacks, choose another reference for a library-selection request. For a specified reference, show the exact blocked slot and the closest supported treatment, including how it changes the test. If only one of two promised benefits is supported, mark the exact adaptation blocked. A one-benefit execution may be proposed separately as a different test. Keep approved names, figures and qualifiers legible at the actual placement crop. Record any change to the control besides the intended test variable.

When adapting an image, distinguish what the picture independently demonstrates from what needs a measurement, label or source. Check what survives the target crop before selecting the line. See [Copy and proof decisions](../evolve-skill/references/book-copy-decisions.md).
