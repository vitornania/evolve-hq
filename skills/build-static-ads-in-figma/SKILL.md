# Plan or build static ads

Choose the work the user asked for first. A browse request ends with sources or a shortlist. Planning and building begin when the user asks for those deliverables.

## Browse static-ad libraries

Use a library link or local source the user provides or has already authorized. For an unfiltered browse request, open the source menu or list the available links by Figma templates, Canva templates, exported images, and ad swipes. In Evolve HQ, use **Browse static-ad libraries** on the workbench to open or save those links. It works without running a skill.

When the user asks you to find or choose a template, start from the product evidence and test objective, then follow [full library review](../adapt-reference-ad/references/reference-review.md). Inventory and assess every in-scope template and verify the finalists at readable size before picking the strongest fit. Report incomplete coverage and continue the review when the missing records can be accessed. A supplied reference can go straight to inspection.

For every substantive ad or template selection, start with the [product research handoff](../adapt-reference-ad/references/reference-review.md#start-with-product-research). Reuse saved findings when available, gather missing evidence before final copy, and trace each on-image claim and supporting visual back to a finding.

## Inputs

Brief, product assets, dimensions, and brand guidance.

## Steps

1. Draft a clear frame at the requested size with visual hierarchy, safe space, and a primary message.
2. Specify assets, typography, spacing, variants, and accessibility details. Use supplied artwork or approved references. Verify the source font from editable metadata or the original PDF when available.
3. Separate the image assets from exact copy and layout. Use approved product photos, offer wording, and logos. Specify which backgrounds or lifestyle images need to be prepared or generated. For a reference build, map the content of every visual and text slot on each page, including images that contain text. Map benefits to benefits and proof to comparable verified proof.

## Deliverable

Return the brief and selection coverage for planning. For a build, use the [local PNG and editable SVG renderer](../adapt-reference-ad/references/local-rendering.md) or the requested connected editor. Use a fresh design, preserve the reference, and check full-size and mobile renders.

Keep source details with the deliverable. Label assumptions and missing evidence. Preserve the scope and any approvals supplied by the user.
