# Plan static Figma ads

Choose the work the user asked for first. A browse request ends with sources or a shortlist. Planning and building begin when the user asks for those deliverables.

## Browse static-ad libraries

Use a library link or local source the user provides or has already authorized. For an unfiltered browse request, open the source menu or list the available links by Figma templates, Canva templates, exported images, and ad swipes. In Evolve HQ, use **Browse static-ad libraries** on the workbench to open or save those links. It works without running a skill.

If the user gives an angle or format, find a small shortlist. Check the original page or frame before describing its visual layout. Say when a link needs access. If the source is unavailable, ask for a link, screenshot, or exported image. A browse request requires no product brief or new image.

## Inputs

Brief, product assets, dimensions, and brand guidance.

## Steps

1. Draft a clear frame at the requested size with visual hierarchy, safe space, and a primary message.
2. Specify assets, typography, spacing, variants, and accessibility details. Use supplied artwork or approved references.
3. Separate the image assets from exact copy and layout. Use approved product photos, offer wording, and logos. Specify which backgrounds or lifestyle images need to be prepared or generated and what should be editable in the final design.

## Deliverable

A layout and design brief with image instructions, approved copy, and export dimensions. An editable Canva or Figma design needs a connected editor session that can create the requested design. Use a fresh design and preserve the reference file. Check the finished result at full size and mobile size before handing it off.

Keep source details with the deliverable. Label assumptions and missing evidence. Preserve the scope and any approvals supplied by the user.
