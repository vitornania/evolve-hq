# Plan or build static ads

Choose the work the user asked for first. A browse request ends with sources or a shortlist. Planning and building begin when the user asks for those deliverables.

## Browse static-ad libraries

Use a library link or local source the user provides or has already authorized. For an unfiltered browse request, open the source menu or list the available links by Figma templates, Canva templates, exported images, and ad swipes. In Evolve HQ, use **Browse static-ad libraries** on the workbench to open or save those links. It works without running a skill.

When the user asks you to find or choose a template, start from the product evidence and test objective, then follow [full library review](../adapt-reference-ad/references/reference-review.md). Inventory and assess every in-scope template and verify the finalists at readable size before picking the strongest fit. Report incomplete coverage and continue the review when the missing records can be accessed. A supplied reference can go straight to inspection.

For every substantive ad or template selection, start with the [product research handoff](../adapt-reference-ad/references/reference-review.md#start-with-product-research). Reuse saved findings when available, gather missing evidence before final copy, and trace each on-image claim and supporting visual back to a finding.

## Inputs

Brief, product assets, dimensions, and brand guidance.

## Steps

1. Draft a clear frame at the requested size with visual hierarchy, safe space, and a primary message.
2. Specify assets, typography, spacing, variants, and accessibility details. Use supplied artwork or approved references. Verify the source font from editable metadata or the original PDF when available.
3. Separate the image assets from exact copy and layout. Use approved product photos, offer wording, and logos. Specify which backgrounds or lifestyle images need to be prepared or generated. For a reference build, map the content of every visual and text slot on each page, including images that contain text. Map benefits to benefits and proof to comparable verified proof. Count claims inside each slot, including each half of a paired-benefit headline. If only one benefit has support, withhold the exact adaptation. A one-benefit layout is a separately labeled alternative test, even if its line breaks match the source.

## Shortlist headlines before layout

Decide what the headline should earn in this placement. For a reader who needs to see how the product works, the line can introduce the product action and the image can supply its visible payoff. For a purchaser waiting on a specific size, item or price, let the verified availability or terms lead. Check what remains intelligible when the headline and image are viewed together. Keep the same selling idea when testing ways of expressing it, including the strength of the claim. A swipe’s numerical specificity or speed claim transfers only with corresponding product evidence.

For a headline selection request, start with the supplied reader, research and product evidence. Give the requested number of options. The portable default is nine short lines grouped into three ideas with two wording alternatives for each lead. Explain the visual device and the product-specific reason to keep each idea in a brief note per group. Keep the selected idea open for the owner or make the choice if delegated. Deliver the shortlist here. Move into layout when the assignment calls for it.

When a sheet or saved index points to a deck, open the current creative and match its identity by brand, title, distinctive artwork or a stable frame ID. Record the sheet row and its historical page separately from the verified current page or frame. Editions can add, move or remove slides at different points. If the match is ambiguous or unavailable, keep attribution unresolved and use independently supported ideas for any remaining work.

In the Evolve Hook Library, use the hook that appears inside the image or video and identify its placement. A feed caption serves a different role. Check the page record when the deck repeats an example or includes a losing iteration and count a repeated creative once. A visual-only reference can inform a proposed action or composition. It supplies no original headline to quote. For the exact Banger Static Ads exercise, open the original in the installed Evolve skill library at `evolve-skill/references/course/02-Evolve-Copywriting-NEW/10-Additional-Resources/02-Banger-Static-Ads-Prompt/prompts/Banger-Static-Ads-Prompt-1uarIpWx.md` when available. If the required research, avatar, product details or confirmation are missing, ask the next original intake question in sequence and pause there. Use already-supplied answers. After confirmation, follow its generation and selection sequence, including its requested iterations. Identify the missing original when only the portable method is available.

## Review the rendered ad in its placement

1. At the intended crop and phone size, read the headline, proof and CTA in order and transcribe the smallest material qualifier. Verify the actual render against the approved slot map, including text inside supplied images. If the offer or qualifier disappears in the crop, adjust the layout and re-export before delivery.
2. When building a variant, mark the element under test and list collateral changes to type, offer, product depiction, or proof. Show which conclusions the resulting comparison can support. A layout plan can be reviewed without a renderer. A production claim needs the inspected export and accessible editable source.

When adapting an image, distinguish what the picture independently demonstrates from what needs a measurement, label or source. Write the exact shopper-visible measurement and qualifier as they should appear on the artwork. Put source IDs and production instructions in the adjacent brief notes. Read every quoted overlay aloud as finished ad copy before selecting the line. Check what survives the target crop. See [Copy and proof decisions](../evolve-skill/references/book-copy-decisions.md).

## Deliverable

Return the brief and selection coverage for planning. For a build, use the [local PNG and editable SVG renderer](../adapt-reference-ad/references/local-rendering.md) or the requested connected editor. Use a fresh design, preserve the reference, and check full-size and mobile renders.

Keep source details with the deliverable. Label assumptions and missing evidence. Preserve the scope and any approvals supplied by the user.
