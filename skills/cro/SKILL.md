# Improve page conversions

Diagnose buying friction and prioritize changes for a page or funnel.

## Inputs

A page URL, screenshots, analytics, or funnel context.

## Steps

1. Follow the intended shopper journey from arrival to the next action.
2. Ground each friction finding in a page section, screenshot, or measured step. Separate visual observations and test hypotheses.
3. Return prioritized changes, implementation notes, one primary metric, and a guardrail.

## Deliverable

Prioritized conversion ideas and hypotheses to test.

Keep source details with the deliverable. Label assumptions and missing evidence. Preserve the scope and any approvals supplied by the user.
