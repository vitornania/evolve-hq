# Improve visibility in AI answers

Find content and evidence gaps that limit discoverability.

## Inputs

Brand, topic, target questions, and existing pages.

## Steps

1. Start with the real user questions that should surface the product.
2. Review available evidence, page structure, naming consistency, and source authority. Separate observed visibility from hypotheses.
3. Recommend answer-ready sections and a repeatable way to check visibility over time.

## Distinguish visibility, recommendation and accuracy

1. Group buyer questions by the decision they represent. Keep the exact prompt, engine, locale, date, and number of observations. Code each answer for a brand mention, a citation with its actual URL, a recommendation for the scenario, and factual accuracy. A citation to an outdated page can increase visibility while giving a shopper the wrong terms.
2. Trace a wrong or unsupported answer to a specific source the assistant cited when possible. Propose a concise answer backed by a canonical specification, policy, or public primary evidence. Track contradictory pages and ownership of the correction.
3. Rerun the same prompt set across comparable settings and report counts with denominators and sampling limits. Keep referral traffic and conversions separate from answer inclusion. A small synthetic prompt panel cannot establish the prevalence of real buyer demand.

## Deliverable

Content improvements and a visibility checklist.

Keep source details with the deliverable. Label assumptions and missing evidence. Preserve the scope and any approvals supplied by the user.
