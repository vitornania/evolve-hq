# Write a video ad script

Create a practical script with spoken lines, shots, and pacing.

## Inputs

Product, audience, angle, length, and available footage.

## Steps

1. Lock the buyer, desire, present belief, objection, substantiated mechanism, proof, offer, CTA, duration and usable footage. Select the route: original concept, direct-competitor territory, cross-category beat structure or native organic format. On a swipe, map the job of each beat before replacing its actors, claims, dialogue and footage with supported material.
2. Plan the first visible action and first spoken line together. Build a credible progression from recognizable situation to product action, appropriate proof and next step. Draft timing, shot, spoken line and on-screen text; distinguish supplied footage from a proposed pickup or demonstration. Keep the spoken copy and CTA clean enough to hand directly to talent.
3. Read the script aloud against the requested duration; distinguish an estimate from a timed recording. Check that the shot can prove the line, and inspect readability and verbal continuity in a separate pass. Offer alternate hooks only when requested. For an original Evolve or Origins prompt run use the installed course routing and integrity verifier; for a supplied voice-over benchmark compare pacing and beat function without inheriting its claims.

For a hook borrowed from a library, identify whether on-screen words, speech or the opening action earns attention in the source. A transcript or primary caption alone cannot establish what appears on the first frame. A visual-only hook can travel as a proposed demonstrable action with verified product facts. Add narration only when the selected format needs it.

If the brief requests the course's modular B-roll test, build three openings from the available mechanism research, new information and customer evidence. Give each hook its own bridge into one shared body and CTA. Write the shared section once, then read each join aloud for continuity. Record the hook and bridge together as the changing unit. For a hook-only experiment keep its continuation fixed. For the exact course exercise, resolve `evolve-skill/references/templates/Evolve - Video Script Prompt.md` within the installed Evolve skill library and apply its duration and awareness limits.

When a story is carrying the sale, check who can tell it firsthand, which event changes the buyer’s belief and where the product evidence earns that change. See [Copy and proof decisions](../evolve-skill/references/book-copy-decisions.md).

## Deliverable

Return a recordable script and a shootable edit plan for the requested scope. Identify missing footage and proof outside the words spoken to the viewer.
